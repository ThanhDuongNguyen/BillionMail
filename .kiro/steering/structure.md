## Key Architectural Patterns

- **GoFrame layered architecture**: `api/` (interface definitions) → `controller/` (HTTP handling) → `logic/` (business rules) → `dao/` (database access) → `model/` (entities)
- **Service registration**: Services are defined as interfaces in `internal/service/` and implemented in `internal/logic/`
- **Frontend feature modules**: Feature-specific code lives in `src/features/` while shared components are in `src/components/`
- **Config-driven containers**: All mail services are configured via mounted config files from `conf/`, not baked into images
- **Shared volumes**: PostgreSQL socket, rspamd data, SSL certs, and logs are shared between containers via Docker volumes
