# Product Overview

BillionMail is an open-source, self-hosted mail server and email marketing platform. It provides:

- Full mail server (SMTP/IMAP/POP3) with Postfix and Dovecot
- Email campaign management (newsletters, promotional, transactional)
- Subscriber/contact list management with tags
- Email template editor
- Advanced analytics (delivery, open rates, click-through)
- Webmail via Roundcube
- DKIM/SPF/DMARC configuration
- Spam filtering via Rspamd
- Multi-domain support with per-domain quotas and rate limiting
- AI-assisted features (AskAI module)
- RBAC (role-based access control) for admin panel
- SSL/TLS certificate management (Let's Encrypt via ACME)
- Fail2ban integration for brute-force protection

Target users: businesses and individuals who want full control over email infrastructure without vendor lock-in.
